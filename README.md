# شیرین حساب (ShirinHesab)

برنامه‌ی مدیریت حساب فروشگاه کیک و شیرینی — ساخته‌شده با Tauri v2
(Rust + TypeScript + HTML/CSS)، رابط فارسی و راست‌چین.

## امکانات
- مدیریت مشتریان: افزودن، ویرایش، حذف
- فاکتور برای هر مشتری: شماره‌ی خودکار، تاریخ شمسی، آیتم‌ها (نام، قیمت واحد، تعداد، جمع کل)
- مدیریت محصولات: ثبت نام و قیمت واحد، انتخاب در فاکتور
- پرداخت‌ها: ثبت پرداخت دستی، تخصیص خودکار به قدیمی‌ترین فاکتورهای پرداخت‌نشده، نمایش بدهکاری
- خروجی PDF فاکتور با لوگوی فروشگاه

- **نسخه‌ی 0.5.0 — پشتیبان‌گیری و انتقال اطلاعات با یک فایل + بهینه‌سازی برای سیستم‌های ضعیف**
- **نسخه‌ی 0.4.1 — تغییر واحد پول به ریال و تبدیل خودکار مبالغ قبلی + بارگذاری دستی فایل آپدیت**
- **نسخه‌ی 0.4.0 — موتور آپدیت درون‌برنامه‌ای (بررسی/دانلود/نصب خودکار + نمایش تغییرات) + صفحه‌ی راهنما + فیکس دوبارشماری «جمع کل فاکتورها» و محاسبه‌ی دقیق‌تر بدهکاری**

## توسعه
```bash
npm install
npm run dev     # اجرای توسعه
npm run build   # بیلد نهایی
```
بیلد ویندوز به‌صورت خودکار در GitHub Actions انجام می‌شود.
